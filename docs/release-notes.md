Vault Gallery brings images, GIFs, videos, audio, and PDFs into one browsable media library inside your vault.

- Folder navigation, media type and tag filters, and search.
- Adjustable thumbnails and sorting by name, modified date, or size.
- Expanded image previews with zoom and video/audio playback.
- Rename files from the details panel while keeping their extension and gallery tags. Obsidian updates note links according to your vault settings.
- Editable tags and descriptions stored locally in plugin data.

### Install with BRAT

1. Install and enable **BRAT** from Obsidian's Community plugins browser.
2. In BRAT, choose **Add a beta plugin** and paste `https://github.com/sahandps/obsidian-vault-gallery`.
3. Add the plugin, enable **Vault Gallery**, and open it from the ribbon or command palette.

For manual installation, download `main.js`, `manifest.json`, and `styles.css` below into `<vault>/.obsidian/plugins/vault-gallery/`, reload Obsidian, and enable the plugin.

This is the initial release. Automated checks and the browser preview pass; live Obsidian and mobile testing are still needed. Media playback depends on the device's codecs. PDFs open in Obsidian's reader. Tags are gallery metadata, not native Obsidian note tags.
